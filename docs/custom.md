## 1. DeepScore 토큰 설계

### 토큰 형식

| 토큰 | 형식 | 예시 |
|---|---|---|
| 특수 | `<PAD>` `<SOS>` `<EOS>` `<UNK>` | — |
| 음자리표 | `clef-{G\|F\|C}` | `clef-G`, `clef-F` |
| 조표 | `key-{name}` | `key-C`, `key-Bb` |
| 박자표 | `time-{num}/{den}` | `time-4/4`, `time-6/8` |
| 음표 | `note-{pitch}{oct}-{dur}` | `note-C4-1/4`, `note-F#5-1/8` |
| 화음 추가음 | `chord-{pitch}{oct}` | `chord-E4`, `chord-G4` |
| 쉼표 | `rest-{dur}` | `rest-1/4` |
| 세로줄 | `barline`, `barline-double`, `barline-final`, `barline-start-repeat`, `barline-end-repeat` | — |

### 음가(duration) 토큰

| 토큰 | 음가 | quarterLength |
|---|---|---|
| `1/1` | 온음표 | 4.0 |
| `3/4` | 점2분음표 | 3.0 |
| `1/2` | 2분음표 | 2.0 |
| `3/8` | 점4분음표 | 1.5 |
| `1/4` | 4분음표 | 1.0 |
| `3/16` | 점8분음표 | 0.75 |
| `1/8` | 8분음표 | 0.5 |
| `3/32` | 점16분음표 | 0.375 |
| `1/16` | 16분음표 | 0.25 |
| `1/32` | 32분음표 | 0.125 |

### 화음 인코딩

가장 낮은 음이 `note-` 토큰, 나머지가 `chord-` 토큰:

```
note-C4-1/4  chord-E4  chord-G4
→ C4+E4+G4 를 4분음표로 연주 (C장조 으뜸화음)
```

### 시퀀스 예시

```
<SOS>  clef-G  key-C  time-4/4
note-C4-1/4  note-E4-1/4  note-G4-1/2
barline
note-F4-1/4  rest-1/4  note-C4-1/4  chord-E4  chord-G4
barline-final
<EOS>
```

### 확장 토큰 설계 상세

**셋잇단음표 (tuplet-3-start/end)**

래퍼 방식으로 기존 note 토큰 재사용:

```
tuplet-3-start
note-C4-1/8    ← 기반 음가 토큰 (실제 음가는 1/3 박)
note-E4-1/8
note-G4-1/8
tuplet-3-end
```

**옥타브 기호 (8va / 8vb)**

토큰 내 음높이는 **실제 연주 음높이** 기준 (악보 표기 그대로가 아님):

```
ottava-8va-start
note-C5-1/4   ← 악보에는 C4로 표기, 8va 범위 내에서 C5로 연주
note-E5-1/4
ottava-8va-end
```

- `ottava-8va-start/end`: 한 옥타브 위
- `ottava-8vb-start/end`: 한 옥타브 아래

**긴 트릴 (trill-start/end)**

`ornament-trill`(단일 음표 짧은 trill)과 구분:

```
trill-start
note-C5-1/2
note-C5-1/4
trill-end
```

### 임시표 기호 처리 방침

> **결론**: 새 토큰 불필요. 절대 pitch 토큰으로 표현 가능.

| 악보 기호 | 처리 방식 |
|---|---|
| ♮ 네츄럴 | 절대 pitch 그대로 출력 (예: F♮ → `note-F4-1/4`) |
| 𝄪 겹올림 | 이명동음 매핑 (예: C𝄪 → `note-D4-…`) |
| 𝄫 겹내림 | 이명동음 매핑 (예: B𝄫 → `note-A4-…`) |

**겹올림 이명동음 매핑**

| 겹올림 | 매핑 토큰 |
|---|---|
| C𝄪 | `note-D{oct}` |
| D𝄪 | `note-E{oct}` |
| E𝄪 | `note-F#{oct}` |
| F𝄪 | `note-G{oct}` |
| G𝄪 | `note-A{oct}` |
| A𝄪 | `note-B{oct}` |
| B𝄪 | `note-C#{oct}` |

**겹내림 이명동음 매핑**

| 겹내림 | 매핑 토큰 |
|---|---|
| C𝄫 | `note-Bb{oct}` |
| D𝄫 | `note-C{oct}` |
| E𝄫 | `note-D{oct}` |
| F𝄫 | `note-Eb{oct}` |
| G𝄫 | `note-F{oct}` |
| A𝄫 | `note-G{oct}` |
| B𝄫 | `note-A{oct}` |

## 2. 커스텀 악보 표기법

> 상태: 규칙 전체 확정. 구현 대상 → Phase 6.

### 2-1. 오선 구조

| 항목 | 규칙 |
|---|---|
| 오선 형태 | 1번선(위)·5번선(아래) 두 줄만 표시하는 **직사각형 박스** |
| 보표 수 | 높은음자리(오른손) + 낮은음자리(왼손) 각 1개, 총 2단 |
| 옥타브 존 | 각 보표를 수직으로 **3등분** → 위·중·아래 존 = 각각 다른 옥타브 |
| 총 옥타브 | 2보표 × 3존 = **6옥타브** 커버 |
| 존 방향 | 위 존 = 높은 옥타브 (피아노 건반과 동일) |

```
높은음자리(오른손)
┌────────────────────┐  ← 위 존  (예: C5~B5)
│                    │
├ ─ ─ ─ ─ ─ ─ ─ ─ ─┤  ← 중 존  (예: C4~B4)
│                    │
├ ─ ─ ─ ─ ─ ─ ─ ─ ─┤  ← 아래 존 (예: C3~B3)
└────────────────────┘

낮은음자리(왼손)
┌────────────────────┐  ← 위 존  (예: C3~B3)
│                    │
├ ─ ─ ─ ─ ─ ─ ─ ─ ─┤  ← 중 존  (예: C2~B2)
│                    │
├ ─ ─ ─ ─ ─ ─ ─ ─ ─┤  ← 아래 존 (예: C1~B1)
└────────────────────┘
```

### 2-2. 음 이름 표기

| 건반 | 표기 | 색상 |
|---|---|---|
| 흰 건반 (C D E F G A B) | 영문 대문자 | 흰색 글자 + 검은 외곽선 |
| 검은 건반 | 숫자 1~5 | 검은색 글자 |

**검은 건반 숫자 매핑**

| 숫자 | 건반 |
|---|---|
| 1 | C# / Db |
| 2 | D# / Eb |
| 3 | F# / Gb |
| 4 | G# / Ab |
| 5 | A# / Bb |

### 2-3. 음가(박자) 표현

- 한 마디 = 박자수만큼 **균등한 셀(cell)** 로 분할 (4/4박 → 4셀)
- 음표는 자신의 음가에 비례하는 셀 수 차지 (2분음표 → 2셀)
- 음표 글자는 차지한 셀들의 **정중앙**에 배치
- 빈 셀 = 쉼표 (별도 기호 없음)

```
4/4박 예시: 2분음표 C + 4분음표 D + 4분음표 E
┌────────┬────┬────┐
│   C    │ D  │ E  │
└────────┴────┴────┘
  ←2셀→   1셀  1셀
```

### 2-4. 음표 셀 색상 테두리

| 순서 | 테두리 색 |
|---|---|
| 1번 음표 | 주황 `#FF8C00` |
| 2번 음표 | 연두 `#7CFC00` |
| 3번 음표 | 하늘 `#00BFFF` |
| 4번+ | 위 순서 반복 |

- 여러 셀을 차지하는 음표는 묶음 전체를 하나의 테두리로 감쌈
- 마디선은 색상 순서를 리셋하지 않음

### 2-5. 화음 표현

| 경우 | 표현 |
|---|---|
| 같은 옥타브 존 내 화음 | 같은 셀 안에 가로로 나열 (예: `CEG`) |
| 다른 옥타브 존 화음 | 같은 열(column), 각 존에 개별 글자 |

### 2-6. 기타 표기 규칙

| 항목 | 규칙 |
|---|---|
| 조표 | 표시 안 함 (변화음은 숫자로 표기) |
| 박자표 | 보표 왼쪽에 숫자 (예: `4/4`) |
| 음자리표 | `T` (Treble) / `B` (Bass) 텍스트 레이블 |
| 쉼표 | 빈 셀 (별도 기호 없음) |
| 셈여림 | 한국어 텍스트 (예: `세게`, `여리게`, `강조`, `짧게`) |
| 도돌이표 | `↩` 기호 또는 텍스트 `반복` |

## 3. Python 렌더러

> 상태: ✅ 구현 완료 (`omr/utils/render_notation.py`)

### 처리 흐름

```
DeepScore JSON 토큰
  → 마디별 그룹화
  → 셀 너비 계산 (음가 비례)
  → 존(zone) 위치 결정 (옥타브 기준)
  → 글자·테두리 색상 할당
  → PIL Canvas.drawRect + Canvas.drawText
  → 커스텀 악보 PNG 출력
```

### 사용법

```bash
python omr/utils/render_notation.py data/train/num1.json --out output/
```

### 구현 내용

- 음가 비례 셀, 색상 테두리(주황·연두·하늘 순환), 옥타브 존 배치
- 흰 건반: 흰 글자+검은 외곽선 / 검은 건반: 검은 숫자
- 화음 같은 존 텍스트 합치기
- 셈여림 한국어 표시
