# music-notation-rule-designer.md

> 담당 에이전트: `music-notation-rule-designer`  
> 관련 파일: `ml/data/tokenizer.json`, `ml/data/round_tokens/`, `ml/omr/utils/render_notation.py`

## 역할

DeepScore 커스텀 토큰 체계를 설계·관리하고, 일반 악보 기호와의 매핑 규칙을 정의한다.  
새 기호 추가 시 vocabulary 확장 방식을 결정하고, 커스텀 악보 표기법 시각 규칙을 유지한다.

## DeepScore 토큰 체계

### 토큰 형식

| 토큰 | 형식 | 예시 |
|---|---|---|
| 특수 | `<PAD>` `<SOS>` `<EOS>` `<UNK>` | — |
| 음자리표 | `clef-{G\|F\|C}` | `clef-G`, `clef-F` |
| 조표 | `key-{name}` | `key-C`, `key-Bb` |
| 박자표 | `time-{num}/{den}` | `time-4/4`, `time-6/8` |
| 음표 | `note-{pitch}{oct}` (다음에 `dur-{dur}` 토큰이 이어짐) | `note-C4 dur-1/4`, `note-F#5 dur-1/8` |
| 화음 추가음 | `chord-{pitch}{oct}` | `chord-E4`, `chord-G4` |
| 쉼표 | `rest-{dur}` | `rest-1/4` |
| 세로줄 | `barline`, `barline-double`, `barline-final`, `barline-start-repeat`, `barline-end-repeat` | — |

## 확장 토큰 규칙

### 셋잇단음표

래퍼 방식으로 기존 note 토큰 재사용:
```
tuplet-3-start
note-C4-1/8    ← 기반 음가 (실제 음가는 1/3 박)
note-E4-1/8
note-G4-1/8
tuplet-3-end
```

### 옥타브 기호

토큰 내 음높이는 **실제 연주 음높이** 기준 (악보 표기 그대로가 아님):
```
ottava-8va-start
note-C5-1/4   ← 악보에는 C4로 표기, 8va 범위 내 C5로 연주
ottava-8va-end
```

### 임시표 처리

새 토큰 불필요. 절대 pitch 토큰으로 표현:

| 기호 | 처리 |
|---|---|
| ♮ 네츄럴 | 절대 pitch 그대로 (`F♮` → `note-F4-1/4`) |
| 𝄪 겹올림 | 이명동음 (C𝄪 → `note-D`, D𝄪 → `note-E`, …) |
| 𝄫 겹내림 | 이명동음 (C𝄫 → `note-Bb`, D𝄫 → `note-C`, …) |

## 커스텀 악보 표기법 규칙

### 오선 구조

- 1번선(위)·5번선(아래) 두 줄만 표시하는 **직사각형 박스**
- 각 보표를 수직으로 **3등분** → 위·중·아래 존 = 각각 다른 옥타브
- 높은음자리(오른손) + 낮은음자리(왼손) 각 1개, 총 2단

```
높은음자리(오른손)
┌────────────────────┐  ← 위 존  (예: C5~B5)
├ ─ ─ ─ ─ ─ ─ ─ ─ ─┤  ← 중 존  (예: C4~B4)
├ ─ ─ ─ ─ ─ ─ ─ ─ ─┤  ← 아래 존 (예: C3~B3)
└────────────────────┘

낮은음자리(왼손)
┌────────────────────┐  ← 위 존  (예: C3~B3)
├ ─ ─ ─ ─ ─ ─ ─ ─ ─┤  ← 중 존  (예: C2~B2)
├ ─ ─ ─ ─ ─ ─ ─ ─ ─┤  ← 아래 존 (예: C1~B1)
└────────────────────┘
```

### 음 이름 표기

| 건반 | 표기 | 색상 |
|---|---|---|
| 흰 건반 (C D E F G A B) | 영문 대문자 | 흰색 글자 + 검은 외곽선 |
| 검은 건반 | 숫자 1~5 | 검은색 글자 |

검은 건반 숫자 매핑: 1=C#/Db, 2=D#/Eb, 3=F#/Gb, 4=G#/Ab, 5=A#/Bb

### 음가 표현

- 한 마디 = 박자수만큼 **균등한 셀**로 분할 (4/4박 → 4셀)
- 음표는 음가에 비례하는 셀 수 차지 (2분음표 → 2셀)
- 음표 글자는 차지한 셀들의 **정중앙**에 배치
- 빈 셀 = 쉼표 (별도 기호 없음)

### 셀 색상 테두리 (음표 순서 기준)

| 순서 | 테두리 색 |
|---|---|
| 1번 음표 | 주황 `#FF8C00` |
| 2번 음표 | 연두 `#7CFC00` |
| 3번 음표 | 하늘 `#00BFFF` |
| 4번+ | 위 순서 반복 |

마디선은 색상 순서를 리셋하지 않음.

### 기타 표기 규칙

| 항목 | 규칙 |
|---|---|
| 조표 | 표시 안 함 (변화음은 숫자로 표기) |
| 박자표 | 보표 왼쪽에 숫자 |
| 음자리표 | `T` (Treble) / `B` (Bass) 텍스트 레이블 |
| 셈여림 | 한국어 텍스트 (`세게`, `여리게`, `강조`, `짧게`) |
| 도돌이표 | `↩` 기호 또는 텍스트 `반복` |
