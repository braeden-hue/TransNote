# ui-design-specialist.md

> 담당 에이전트: `ui-design-specialist`  
> 관련 코드: `lib/screens/`, `lib/widgets/`, `online_webpage/`

## 역할

앱·웹의 모든 UI/UX 요소를 설계하고 개선한다.  
튜토리얼 온보딩, 악보 촬영 화면, 커스텀 악보 생성 에디터가 핵심 관할 영역이다.

---

## 현재 구현된 화면

### 1. 튜토리얼 화면 (`lib/screens/tutorial_screen.dart`)

- PageView 3단계: 커스텀 표기법 규칙 설명 + 미니 악보 미리보기
- 각 단계에서 옥타브 존, 음 이름 표기, 음가 셀 개념 소개
- 마지막 단계에서 악보 화면으로 이동 CTA 버튼

### 2. 악보 화면 (`lib/screens/score_screen.dart`)

- 샘플 악보 선택 그리드 (반짝반짝·학교종이 등)
- 선택 후: 커스텀 표기법 악보 + 88건반 피아노 위젯

### 3. 연습 화면 (`lib/screens/practice_screen.dart`)

- 순서대로 음 누르기 연습 모드
- 정답: 초록 하이라이트 / 오답: 빨간 깜빡임

### 4. 악보 렌더러 (`lib/widgets/notation_widget.dart`)

CustomPainter 기반. 시각 규칙:
- **직사각형 박스** 2단 (높은음자리 + 낮은음자리)
- 각 보표를 수직 3등분 → 옥타브 존
- 음가 비례 셀, 색상 테두리(주황→연두→하늘 순환)
- 흰 건반: 영문 대문자 (흰색 글자+검은 외곽선), 검은 건반: 숫자 1~5

### 5. 피아노 위젯 (`lib/widgets/piano_widget.dart`)

- 88건반, 터치 하이라이트
- 오답 시 빨간 깜빡임 애니메이션

## Phase 6-2 — Flutter CustomPainter 구현 계획

`ml/omr/utils/render_notation.py` (Python, ✅ 완료) 로직을 Dart `CustomPainter`로 포팅.

### 렌더링 처리 흐름

```
DeepScore 토큰 리스트
  → 마디별 그룹화
  → 셀 너비 계산 (음가 비례)
  → 존(zone) 위치 결정 (옥타브 기준)
  → 글자·테두리 색상 할당
  → Canvas.drawRect + Canvas.drawText
  → 커스텀 악보 렌더링
```

성능 문제 시: C++ + OpenCV로 이미지 생성 후 Flutter에 전달하는 방식으로 전환.

## 악보 촬영 화면 (Phase 5 — 미구현)

```
카메라 뷰파인더 (camera 패키지)
  ├── 악보 정렬 가이드 오버레이 (직사각형 가이드라인)
  ├── 촬영 버튼 (하단 중앙)
  ├── 갤러리 선택 버튼 (하단 우측)
  └── 처리 중 스피너 → 결과 화면 전환
```

UX 원칙:
- 촬영 즉시 전처리 진행 (사용자 확인 불필요)
- 실패 시 "다시 촬영" 옵션 제공
- 카메라 권한 거부 시 갤러리 모드로 graceful fallback

## 확장 UI 기능 (인식률 90%+ 이후)

### 동시음 연결선 (Phase 6-3)

- 두 보표 사이 얇은 수직 점선
- 연결선 색상 = 해당 열 음표의 색상 테두리와 동일
- 한쪽이 쉼표이면 연결선 없음

### 플레이헤드 (Phase 6-4)

```
4/4박 한 마디 — 2번째 셀 재생 중:
┌────┬▓▓▓▓┬────┬────┐
│ C  │▓D▓ │ E  │    │
└────┴▓▓▓▓┴────┴────┘
```

| 플랫폼 | 구현 |
|---|---|
| 웹 | `requestAnimationFrame` 루프 |
| 앱 | Flutter `AnimationController` + `Ticker` |

### MIDI 재생 UX

- 재생/일시정지/정지 버튼
- BPM 슬라이더 (50~150%)
- 재생 중 음표 하이라이트

## 시각적 규칙 요약 (커스텀 악보 표기)

| 요소 | 규칙 |
|---|---|
| 흰 건반 | 영문 대문자, 흰색 글자 + 검은 외곽선 |
| 검은 건반 | 숫자 1~5, 검은색 글자 |
| 음가 셀 | 음가 비례 너비, 정중앙에 글자 배치 |
| 색상 테두리 | 주황(`#FF8C00`) → 연두(`#7CFC00`) → 하늘(`#00BFFF`) 순환 |
| 쉼표 | 빈 셀 (별도 기호 없음) |
| 셈여림 | 한국어 텍스트 (`세게`, `여리게`, `강조`, `짧게`) |
| 도돌이표 | `↩` 기호 |
