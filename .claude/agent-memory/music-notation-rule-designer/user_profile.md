## 프로젝트 성격

- 초보자 진입장벽 제거가 1차 목표였으나
- 경험 있는 음악가에게도 흥미로운 novelty 제공을 추가 목표로 설정
- online_webpage는 JS/SVG 기반 프로토타입으로 빠른 시각화 실험 가능한 환경

## 기술 스택

- Frontend: Vanilla JS + SVG (online_webpage)
- Mobile: Flutter + Dart + Kotlin (Android)
- ML: TFLite + ONNX Runtime (C++ pipeline)
- tokenizer.json 기반 음표 시퀀스 토큰화

## 협업 방향

- 커스텀 악보 기호 정의 및 규칙 설계 요청 가능성 높음
- notation.js 직접 수정 제안 형태로 작업할 때 효율적
